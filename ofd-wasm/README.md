# OFD WASM 阅读器

本目录原先是 OFD WASM 阅读器的一份独立副本，现已停止维护，改为跳转到新的发布地址：

- 在线阅读器：<https://zc310.github.io/ofd/wasm/>
- 项目源码：<https://github.com/zc310/ofd>

阅读器随 `zc310/ofd` 仓库发布，源码位于 [`cmd/ofd-wasm/web`](https://github.com/zc310/ofd/tree/main/cmd/ofd-wasm/web)，由该仓库的 GitHub Actions 部署。功能说明、构建方式和 JavaScript API 文档都以那边的 [`README.md`](https://github.com/zc310/ofd/blob/main/cmd/ofd-wasm/web/README.md) 为准。

本目录只保留一个提示跳转的 `index.html`，6 秒后自动跳转到新地址；原先的 `ofd.wasm`、`viewer.js`、`worker.js` 等构建产物已删除。
